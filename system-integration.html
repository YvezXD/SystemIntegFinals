Problem Statement & Significance

Information about Siargao Island's traditional handicrafts (such as buri hats, salakot, nigo trays, sungka boards, and rattan weaving) is rarely documented online in a structured format. This system preserves local cultural knowledge and exposes it via a reusable REST API for tourism portals, schools, and local livelihood platforms.

Target Users

1. Local Artisans & Cooperatives: Showcase products from Dapa, Del Carmen, General Luna, Pilar, and San Isidro.
2. Tourists & Cultural Researchers: Discover authentic Siargaonon crafts, materials, and local names.
3. Third-Party Developers: Reuse the JSON REST API in mobile or tourism apps.

Validation, Security & Error Handling

• Prepared Statements: All SQL queries use $conn->prepare() and bind_param() to prevent SQL Injection.
• Server & Client Validation: Checks required fields before POST / PUT.
• HTTP Status Codes: Returns 200, 201, 400, 404, and 405 accurately.

Limitations & Future Improvements

• Current Limitation: Designed as a local knowledge repository without online payment processing or user login roles.
• Future Improvements: Add JWT authentication for admin actions, direct photo file uploads, interactive Siargao map pins, and multi-language translations.
